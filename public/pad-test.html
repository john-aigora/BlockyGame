How to read this for Blocky
  1. Each card is one gamepad.index. Dual DB9 USB adapters often show two cards with the same name: one is live, one stays at zero (ghost).
  2. Blocky solo uses the pad with the highest activity. 2P seats claim only after a stick or D-pad move clears the deadzone.
  3. F310 on D: mapping is empty / DirectInput. Left stick is axes 0 and 1. A is button 1, B is 2, X is 0, Y is 3, Back is 8, Start is 9.
  4. If one stick never moves axes 0/1 here, Blocky cannot drive a hero with it either — try the other USB port, unplug/replug, or Chrome’s gamepad list after a refresh.
